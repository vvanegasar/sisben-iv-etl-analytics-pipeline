# Data in this folder

This folder holds only public reference data and synthetic samples. It never holds SISBEN IV microdata.

## Synthetic samples (`sample/`)

| File | Content |
|---|---|
| `sample/sisben_synthetic_sample.csv` | **Synthetic.** 302 invented person rows (5 municipalities × 6 snapshots, 2021–2026) with the 111 base columns of the fact table. `Source.Name` is `SINTETICO_NO_REAL_<year>.csv` and `NOM_BARRIO` is `BARRIO SINTETICO <n>` on every row. |
| `sample/poblacion_synthetic_sample.csv` | **Synthetic.** Invented population projections in the format read by `src/etl/etl_poblacion_cobertura.py`. Column `FUENTE` is `SINTETICO` on every row. |

Both files are generated by `scripts/generate_synthetic_sample.py` with seed 2026. No value comes from a real record:
only the column names, the code ranges used by the ETL and the public DIVIPOLA municipality codes are real.

## Not included

- **SISBEN IV microdata.** It is personal data protected by Colombian Law 1581 of 2012, and the pipeline reads it from paths you configure.
- **The population projections file used in production.** Configure your own with `SISBEN_POBLACION_CSV`. The sample above shows the expected columns.
- **The SISBEN IV variable dictionary.** The column names follow the layout of DNP's anonymized SISBEN IV database. See DNP's official SISBEN documentation at <https://www.sisben.gov.co>.
- **The territorial workbook read by the Power BI table `dim_municipios`.** It adds subregions and other territorial groupings to DIVIPOLA. The model reads it through the `DivipolaWorkbookPath` parameter.
